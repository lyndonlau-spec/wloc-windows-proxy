# Security Policy

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Do not open a public issue for certificate, proxy exposure, request-rewriting, or code-execution vulnerabilities.

Use GitHub's **Security → Report a vulnerability** form to submit a private report. Include:

- affected version or commit;
- Windows and Python versions;
- minimal reproduction steps;
- expected and observed behavior;
- impact on an authorized test deployment.

Reports about using the project on devices or networks without authorization are out of scope.
